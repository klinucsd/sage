# ARGUS Example Notebooks

These notebooks demonstrate ARGUS across multiple scientific domains. Each `.ipynb` in this folder is the JupyterHub source; the Colab badges open a Colab-ready variant in [`examples/colab/`](colab/) that includes the install bootstrap, so the recipient can just hit *Run all*.

| [blake_ridge_hydrate.ipynb](blake_ridge_hydrate.ipynb) | `%%skill-build` turns a Zenodo record that mixes HDF5 arrays and tabular files into one queryable skill — ARGUS detects that the arrays and tables share a grid, joins them automatically, and pauses for approval on the plan (including the exact join) before building. Uses a Blake Ridge gas-hydrate PFLOTRAN simulation (Eymold 2021, *G-Cubed*). | [![Open in Colab](https://raw.githubusercontent.com/klinucsd/sage/main/assets/colab-badge-large.svg)](https://colab.research.google.com/github/klinucsd/sage/blob/main/examples/colab/blake_ridge_hydrate_colab.ipynb) |

Uses one year of atmospheric measurements from the ATLASM5 station (EU H2020 MARSU; Mellouki 2020). | [![Open in Colab](https://raw.githubusercontent.com/klinucsd/sage/main/assets/colab-badge-large.svg)](https://colab.research.google.com/github/klinucsd/sage/blob/main/examples/colab/atlasm5_marsu_2019_colab.ipynb) |
